A disk cleaner that can't hurt your Mac.

macclean finds caches, logs, and data left behind by uninstalled apps — then deletes through the Trash, so every cleanup is undoable. Nothing is removed until you say so.

Download for macOS View on GitHub

Apple Silicon · macOS 11+ · MIT license

Safe by construction

Only files your tools can fully regenerate are pre-selected — package caches, build artifacts, logs. Anything ambiguous is shown as review and stays unticked.

The Trash is the undo

Every deletion goes through NSFileManager — the same Trash Finder uses. Changed your mind? Select a file in the Trash and choose Put Back. No rm, ever.

Finds what apps leave behind

macclean reads the bundle ID of every installed app and flags Library data that matches nothing — orphaned caches, containers, preferences, and launch agents paid cleaners charge you for.

What it scans

CategoryWhat's foundSafety
Developer caches npm, bun, pnpm, yarn, uv, pip, Go modules, Cargo, Gradle, Maven, Deno, Xcode DerivedData safe
Developer data CoreSimulator devices, Xcode Archives, iOS DeviceSupport review
Cleanup commands brew cleanup -s, xcrun simctl delete unavailable — the tool's own cleanup, never a file delete safe
App caches ~/Library/Caches and cache subdirectories of installed apps safe
App leftovers Application Support, Containers, Group Containers, LaunchAgents, Preferences whose owning app is gone review
Downloads .dmg / .pkg installers left in ~/Downloads review
Logs ~/Library/Logs and Homebrew service logs (truncated in place so daemons keep running) safe

Never touched: documents, session data, cookies, IndexedDB, LocalStorage, keychains, or anything under /System.

    see the note below

Unsigned build — one extra click on first launch.

macclean isn't notarized by Apple, so macOS blocks the first double-click. Right-click the app → Open → confirm once; it launches normally forever after. Or from a terminal:

xattr -d com.apple.quarantine /Applications/macclean.app
